---
title: Local Setup
description: Run the Anspectra control plane, data services, and local Camoufox collector.
---

## Requirements

- macOS or Windows
- Node.js 20+
- pnpm 10+
- Docker Desktop
- Python 3.12

## 1. Configure

```bash
git clone https://github.com/MYZ8088/anspectra.git
cd anspectra
cp .env.example .env
pnpm install
```

Set an OpenAI-compatible analysis endpoint in `.env`:

```bash
LLM_BASE_URL=https://your-endpoint.example/v1
LLM_API_KEY=replace-with-your-key
LLM_MODEL=your-model-name
```

The configured model structures captured answers. It does not provide formal
monitoring samples.

## 2. Provision Camoufox

```bash
pnpm camoufox:setup
pnpm camoufox:doctor
```

The runtime and persistent provider profiles live under `.anspectra-storage/`,
which is excluded from Git and Docker build contexts.

## 3. Start Anspectra

```bash
pnpm local
```

Open [http://localhost:3000](http://localhost:3000). `pnpm local` starts
PostgreSQL, ClickHouse, Redis, the Next.js app, and the collector.

## 4. Connect providers

Open Providers and connect each official Web account. The same persistent
profile is used for sign-in and later collection. Normal detection uses a
headed window that is automatically minimized; sign-in, inspection, or human
verification restores that same real provider window.

## 5. Create a detection

Use New Detection to scan a product website, confirm its profile, select a
fixed suite, preview all prompts, and start a versioned detection series. Arbitrary custom
prompts are not accepted in formal Anspectra reports.
