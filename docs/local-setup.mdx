title: Local Setup
description: Run the Aloom control plane, data services, and local Camoufox collector.
---

## Requirements

- macOS or Windows
- Node.js 20+
- pnpm 10+
- Docker Desktop
- Python 3.12

## 1. Configure

```bash
git clone https://github.com/MYZ8088/aloom.git
cd aloom
cp .env.example .env
pnpm install
```

Model API credentials do not belong in `.env`. After the app starts, the
workspace owner configures an OpenAI-compatible API base URL, model ID, and API
key in Settings.

## 2. Provision Camoufox

```bash
pnpm camoufox:setup
pnpm camoufox:doctor
```

The runtime and persistent provider profiles live under `.aloom-storage/`,
which is excluded from Git and Docker build contexts.

## 3. Start Aloom

```bash
pnpm local
```

Open [http://localhost:3000](http://localhost:3000). `pnpm local` starts
PostgreSQL, ClickHouse, Redis, the Next.js app, and the collector.

Open Settings, save the analysis model connection, and run its connection test
before starting a formal detection.

## 4. Connect providers

Open Providers and connect each official Web account. The same persistent
profile is used for sign-in and later collection. Normal detection uses a
headed window that is automatically minimized; sign-in, inspection, or human
verification restores that same real provider window.

## 5. Create a detection

Use New Detection to scan a product website, confirm its profile, select a
fixed suite, preview all prompts, and start a versioned detection series. Arbitrary custom
prompts are not accepted in formal Aloom reports.
