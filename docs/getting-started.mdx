## Choose a control plane

| Capability | Local stack | Self-hosted control plane |
|---|---:|---:|
| Product profile and prompt preview | Yes | Yes |
| Official Web collection | Local collector | Paired local collector |
| Recurring schedules | Yes | Yes |
| Provider cookies uploaded | Never | Never |
| Full data ownership | Yes | Yes |

- [Local Setup](/local-setup) runs the control plane, databases, and collector
  on one macOS or Windows machine.
- [Self-Hosted Setup](/self-hosted-setup) runs the control plane and databases
  on your server while a paired collector remains on the user's computer.

## First detection

1. Configure an analysis provider, normally AIHubMix.
2. Run `pnpm camoufox:setup` and `pnpm camoufox:doctor` on the collector machine.
3. Connect Doubao, DeepSeek, Yuanbao, and Qwen under Providers.
4. Scan the official product website and confirm the product profile.
5. Choose a fixed detection suite, provider modes, languages, and sampling depth.
6. Review every rendered prompt and click **Run detection**.

Provider login and human verification must be completed by the account owner.
Aloom does not solve or bypass CAPTCHA challenges.
