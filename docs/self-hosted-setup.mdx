---
title: Self-Hosted Setup
description: Host the Aloom control plane while official Web sessions remain on a paired user computer.
---

## Architecture

The server runs the Web app, PostgreSQL, ClickHouse, Redis, and migrations. It
does not run provider browsers and never stores provider cookies. A macOS or
Windows collector polls the server over outbound HTTPS, executes official Web
tasks locally, and uploads only sample results and task events.

## Server requirements

- Ubuntu 22.04 or 24.04
- 4 vCPU and 8 GB RAM recommended
- Docker and Docker Compose
- A DNS name with HTTPS

## 1. Clone and configure

```bash
git clone https://github.com/MYZ8088/aloom.git /opt/aloom
cd /opt/aloom
cp .env.example .env
```

Set the public URL, database secrets, auth secrets, and analysis provider. Do
not configure provider cookies, browser profiles, or proxy rotation on the
server.

## 2. Start the control plane

```bash
pnpm install
pnpm self-host:build
```

The default Compose project is `aloom`. The collector service is not part of
the default production stack.

Place `http://127.0.0.1:3000` behind your HTTPS reverse proxy. Only SSH and
HTTP/HTTPS need to be exposed publicly; PostgreSQL, ClickHouse, and Redis bind
to loopback or private Docker networks.

## 3. Pair a collector

In the Providers screen, create a collector pairing. Copy the one-time device
token to the user's computer and configure:

```bash
COLLECTOR_API_URL=https://aloom.example.com
COLLECTOR_DEVICE_TOKEN=aloom_collector_replace-with-the-one-time-token
```

Then run on the user's macOS or Windows machine:

```bash
pnpm install
pnpm camoufox:setup
pnpm camoufox:doctor
pnpm collector
```

The collector uses the user's current network. It does not rotate IP addresses
or upload its browser profile. Provider sign-in is completed locally under
Providers.

## 4. Verify

The Providers page should show the collector heartbeat and one health row per
provider. If the machine sleeps or goes offline, scheduled work remains in
`waiting_runner` and resumes when the collector reconnects.

## Updates

```bash
cd /opt/aloom
git pull
pnpm self-host:build
```

Database migrations are non-destructive. Back up the Aloom PostgreSQL and
ClickHouse volumes before production upgrades.
