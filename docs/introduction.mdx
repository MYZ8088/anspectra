## Detection, not approximation

Anspectra is an open-source GEO detection and recurring monitoring product. It
collects the answer rendered in the official Doubao, DeepSeek, Yuanbao, and
Qwen Web interfaces. Model API output is never substituted for a monitoring
sample.

Each formal series starts from a fixed, versioned prompt pack. Every prompt is
executed in a fresh conversation and records the requested mode, actual mode,
answer, visible sources, conversation identity, and collection status.

## Fixed prompt coverage

The Anspectra GEO Detection Pack contains 54 templates per language: nine intents
across six buyer stages. Ready-made suites select deterministic parts of that
matrix, from an 18-question Quick Scan to the complete 54-question Full Matrix.

Sampling depth is separate from prompt coverage:

- Single runs one sample per prompt and provider.
- Reliable runs two rounds at least six hours apart.
- Stability runs three rounds across three calendar days.

## Local browser privacy

Official Web collection runs on the user's macOS or Windows collector with one
persistent Camoufox profile per provider. Normal sampling uses a headed window
that is automatically minimized. Explicit inspection, sign-in, QR confirmation,
CAPTCHA, or another human-verification event restores that same real window.

Cookies, local storage, and browser profiles never leave the collector machine.
The control plane receives only task events and captured samples through
outbound HTTPS requests authenticated by a workspace-scoped device token.

## Analysis and reporting

Each captured answer is analyzed independently against a strict JSON Schema.
Anspectra can extract and repair common JSON defects, try a configured fallback
model, and run one conservative repair pass. Analysis failures remain separate
from collection failures.

Reports are then aggregated deterministically across provider, official Web
mode, language, intent, decision stage, blind or aided exposure, product,
competitor, audience, region, and individual prompt. Failed or blocked samples
remain in the denominator.
