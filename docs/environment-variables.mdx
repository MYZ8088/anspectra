---
title: Environment Variables
description: Current Aloom control-plane, analysis, and local-collector configuration.
---

## Core services

| Variable | Default | Purpose |
|---|---|---|
| `DATABASE_URL` | local PostgreSQL | Product profiles, manifests, schedules, and checkpoints |
| `CLICKHOUSE_URL` | `http://localhost:8123` | Captured answers, sources, and analyses |
| `REDIS_HOST` | `localhost` | BullMQ and local runtime coordination |
| `REDIS_PORT` | `6379` | Redis port |
| `REDIS_PASSWORD` | `redis` | Redis password |
| `APP_URL` | `http://localhost:3000` | Public Web origin |
| `BETTER_AUTH_SECRET` | generated | App session signing secret |
| `INTERNAL_CRON_SECRET` | generated | Internal schedule trigger secret |

## Analysis

| Variable | Default | Purpose |
|---|---|---|
| `ANALYSIS_LLM_PROVIDER` | `aihubmix` | `aihubmix`, `openai`, or `claude` |
| `AIHUBMIX_API_KEY` | none | Default structured answer analysis |
| `AIHUBMIX_BASE_URL` | `https://aihubmix.com/v1` | OpenAI-compatible AIHubMix endpoint |
| `AIHUBMIX_ANALYSIS_MODEL` | configured model | Primary analysis model |
| `AIHUBMIX_ANALYSIS_FALLBACK_MODEL` | configured model | Schema-recovery fallback |
| `OPENAI_API_KEY` | none | Optional OpenAI analysis backend |
| `ANTHROPIC_API_KEY` | none | Optional Anthropic analysis backend |

Analysis keys are not used to collect official Web samples.

## Local collector

| Variable | Default | Purpose |
|---|---|---|
| `COLLECTOR_API_URL` | none | HTTPS control-plane origin for a paired collector |
| `COLLECTOR_DEVICE_TOKEN` | none | Workspace-scoped collector token |
| `CAMOUFOX_PYTHON_BIN` | managed virtual environment | Python executable override |
| `CAMOUFOX_PIP_SPEC` | pinned Camoufox 0.5.5 | Runtime package override |
| `CAMOUFOX_BROWSER_CHANNEL` | pinned official stable channel | Browser binary override |
| `DEBUG_ENABLED` | `false` | Verbose local collector logs |

Provider cookies, local storage, and browser profiles are intentionally not
represented by environment variables and are never uploadable. They remain in
the ignored `.aloom-storage/` directory on the collector machine.

## Docker

| Variable | Default | Purpose |
|---|---|---|
| `POSTGRES_DB` | `aloom` | PostgreSQL database name |
| `CLICKHOUSE_DB` | `aloom` | ClickHouse database name |
| `ALOOM_STORAGE_ROOT` | `/opt/aloom/storage` | Control-plane storage root |
| `ALOOM_WEB_IMAGE` | local build | Optional Web image override |
| `ALOOM_POSTGRES_IMAGE` | local build | Optional PostgreSQL image override |
