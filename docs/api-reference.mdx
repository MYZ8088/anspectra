## Commands

```bash
pnpm local                 # local control plane, data services, and collector
pnpm collector             # local collector only
pnpm auth                  # local provider sign-in helper
pnpm camoufox:setup        # provision the pinned Python/browser runtime
pnpm camoufox:doctor       # validate Python, Camoufox, browser, GeoIP, and paths
pnpm check:english         # reject user-facing non-English product text
pnpm check:privacy         # reject secrets, profiles, cookies, and raw run data
pnpm test                  # unit and DOM fixture tests
pnpm typecheck             # workspace TypeScript validation
pnpm build                 # production build with language and privacy gates
```

## Product routes

| Route | Purpose |
|---|---|
| `/dashboard` | Selected formal series and hierarchical detection report |
| `/monitor` | Product scan, suite selection, prompt preview, and new detection |
| `/prompt-library` | Read-only preset packs and frozen workspace sets |
| `/runs` | Checkpoints, provider progress, failure classes, and human verification |
| `/schedule` | Weekly or monthly frozen detection schedules |
| `/providers` | Local sessions, collector pairing, and diagnostics |
| `/settings` | Workspace and account settings |

## Formal providers

| Provider | Supported official modes |
|---|---|
| Doubao | Provider default, Fast, Expert |
| DeepSeek | Provider default, Fast, Expert, Reasoning, Web Search, Reasoning + Web Search |
| Yuanbao | Provider default, Automatic Search, Reasoning |
| Qwen | Provider default, Auto, Fast, Reasoning |

Every baseline sample uses a fresh conversation. An unavailable requested mode
fails explicitly and is never silently replaced by another mode.
